# CraveSmart - Food recommendation web application

# Project Description
This is web-based food recommendation system developed to help students find a suitable food
spot based on their food preference and budget easily. Users can create and account, log in, 
browse food recommendations, change their home page theme from dark mode or light mode based on their preference and save their favourite foods for future reference.

# Features
- User registration
- User login
- Food recommendation
- Favourite foods
- User session management
- Logout 

# Technologies/Language/Framework used
- Python
- Flask 
- HTML
- CSS
- JavaScript
- SQLite
- SQLAlchemy

# Installation
1. Create and clone the repository
2. Install the required packages: 
    pip install -r requirements.txt
3. Run the application:
   python web.py
4. Open the browser and visit the local URL:
   http://127.0.0.1:5000

# Project structure
- web.py : Main Flask application
- templates/ : HTML files
- static/ : CSS, JavaScript, and Images
- database.db : SQLite database
- requirements.txt - Python dependencies for deployment
